# TAVI – Детектор ключевых точек на основе тепловых карт

Этот репозиторий реализует подход для обнаружения ключевых точек на медицинских изображениях с использованием тепловых карт. Основной идеей является регрессия тепловых карт, где для каждой ключевой точки генерируется отдельный канал. В качестве базовой архитектуры используется модифицированная версия HRNet, адаптированная для задачи обнаружения ключевых точек.

## Основные возможности

- **Модель на основе тепловых карт:**  
  Модель генерирует для каждого класса ключевой точки отдельную тепловую карту, затем с помощью процедуры извлечения пиков (argmax с уточнением центра масс) определяет координаты ключевых точек.

- **HRNet-бэкбон:**  
  Используется HRNet для извлечения признаков с разных разрешений. Последний слой заменён на сверточный слой (heatmap_head), который выдаёт нужное число каналов – по одному на каждую ключевую точку.

- **Кастомная функция потерь:**  
  Для обучения применяется функция потерь [HeatmapLoss](#), которая на начальном этапе использует стандартную MSE Loss, а также имеет опциональную реализацию Focal Loss для борьбы с несбалансированностью данных.

- **Аугментация данных:**  
  В датасете реализованы разнообразные аугментации:  
  - Случайное изменение яркости и контраста  
  - Размытие и добавление шума  
  - Случайное масштабирование, поворот и горизонтальное отражение  
  Это помогает улучшить обобщающую способность модели.

- **Визуализация результатов:**  
  Для контроля обучения реализована функция визуализации, которая сохраняет батч изображений с нанесёнными ground truth и предсказанными ключевыми точками, а также накладывает суммарную тепловую карту.

- **Логирование и сохранение чекпоинтов:**  
  Используется TensorBoard для мониторинга процесса обучения, а также сохраняются лучшие модели и периодические контрольные точки.

## Структура репозитория

- **`train.py`**  
  Основной скрипт для обучения. Загружает конфигурацию из `config.yaml`, инициализирует датасет, модель, оптимизатор, планировщик скорости обучения и TensorBoard. В ходе обучения выводятся промежуточные метрики, а также сохраняются визуализации батчей.

- **`heatmap_model.py`**  
  Определяет класс `HeatmapKeypointModel`, который использует HRNet как бэкбон. Модель выполняет два основных шага:
  1. Генерация тепловых карт посредством сверточного слоя.
  2. Извлечение координат ключевых точек из тепловых карт (с пороговой проверкой и уточнением координат методом центра масс).

- **`dataset.py`**  
  Реализует класс `TAVIDataset`, предназначенный для загрузки изображений и JSON-аннотаций. В процессе загрузки выполняется:
  - Извлечение координат ключевых точек с учетом вариантов имен (русская/английская C).
  - Применение аугментаций (поворот, масштабирование, отражение, шум, размытие и коррекция яркости/контраста).
  - Приведение изображений к требуемому формату и нормализация.

- **`losses.py`**  
  Содержит альтернативную комбинированную функцию потерь для задачи обнаружения ключевых точек, включающую:
  - Focal Loss для предсказания наличия ключевой точки.
  - Wing Loss (или Smooth L1) для регрессии координат.
  - Дополнительную компоненту для групповой классификации (на основе группировки точек).

- **`config.yaml`**  
  Файл конфигурации, где задаются пути к данным, параметры обучения (batch size, learning rate, количество эпох, число рабочих потоков), настройки модели (размер тепловой карты, параметры гауссова распределения, параметры focal loss) и параметры визуализации.

- **Дополнительные файлы:**  
  - Скрипты визуализации (например, функция `visualize_heatmaps_and_keypoints`) – отвечают за построение графиков с нанесением предсказанных ключевых точек и тепловых карт.
  - Модуль HRNet (файл `hrnet_model.py`) – отвечает за извлечение признаков; данный файл подключается внутри `heatmap_model.py`.

## Подготовка данных

Датасет должен иметь следующую структуру (пример для разделённого набора 512×512):

```
/TAVI_512_split/
  ├── train/
  │    ├── case_1/
  │    │      ├── img/         # Изображения
  │    │      └── ann/         # JSON-аннотации с расширением .png.json
  │    ├── case_2/
  │    │      ├── img/
  │    │      └── ann/
  │    └── ...
  └── val/
       ├── case_1/
       │      ├── img/
       │      └── ann/
       └── ...
```

При загрузке аннотаций используется функция `extract_points_from_json`, которая извлекает координаты ключевых точек, нормализует их и сопоставляет с предопределённым списком классов (группы точек – group_1, group_2, group_3).

## Установка и запуск

### Требования

- Python 3.7+
- PyTorch (версия, совместимая с вашим CUDA/CPU)
- NumPy
- OpenCV (cv2)
- Matplotlib
- TensorBoard

### Установка зависимостей

Создайте и активируйте виртуальное окружение (рекомендуется):

```bash
python -m venv venv
source venv/bin/activate  # для Linux/macOS
venv\Scripts\activate  # для Windows
```

Установите необходимые библиотеки:

```bash
pip install torch torchvision numpy opencv-python matplotlib tensorboard pyyaml
```

### Настройка конфигурации

Отредактируйте файл [config.yaml](config.yaml) в соответствии с вашим окружением:
- Задайте путь к датасету (`dataset_path`).
- Настройте параметры обучения (batch size, learning rate, epochs, num_workers).
- При необходимости измените параметры модели и визуализации.

### Запуск обучения

Для начала обучения выполните:

```bash
python train.py
```

В процессе обучения:
- На экран будут выводиться метрики (потери, время эпохи).
- Лучшие модели сохраняются в директории, указанной в `checkpoint_dir`.
- Визуализации батчей (с наложением предсказанных точек и тепловых карт) сохраняются в директории, указанной в параметрах визуализации.

### Мониторинг TensorBoard

Чтобы просматривать логи TensorBoard, запустите:

```bash
tensorboard --logdir=runs
```

и перейдите по адресу, указанному в терминале.

## Пример визуализации

Визуализация включает три колонки:
1. **Ground Truth:** Исходное изображение с нанесёнными истинными ключевыми точками.
2. **Predictions:** Исходное изображение с предсказанными точками (отмечены зелёными метками).
3. **Predicted Heatmap:** Изображение с наложенной суммарной тепловой картой, демонстрирующей интенсивность предсказания.

Такая визуализация позволяет оценить, насколько хорошо модель «понимает» расположение ключевых точек.

## Обзор подхода

Подход основан на следующих ключевых идеях:
- **Тепловая регрессия:** Прямое предсказание тепловых карт для каждой ключевой точки позволяет модели захватывать пространственные зависимости и более точно локализовать точки.
- **HRNet-бэкбон:** Использование многоуровневых признаков с разными разрешениями улучшает качество извлечённых признаков и, соответственно, точность детекции.
- **Адаптивная функция потерь:** Комбинированная функция потерь (с использованием MSE, Focal Loss, Wing Loss) обеспечивает баланс между точностью регрессии координат и устойчивостью к несбалансированным данным.
- **Аугментация данных:** Широкий набор аугментаций помогает улучшить обобщающую способность модели, особенно при ограниченном объёме данных.
